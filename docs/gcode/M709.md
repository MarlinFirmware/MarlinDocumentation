---
tag: m0709
title: "M709: MMU Power and Reset"
short_title: MMU Power and Reset
brief: Enable, disable or reset the MMU
author: perkins
parent: G-code Commands
group: control
since: 2.1.3
requires: PRUSA_MMU3
codes: [ M709 ]
related: [ M704, M707, M708 ]

notes:
- "`S` is saved to EEPROM when `EEPROM_SETTINGS` is enabled, so a disabled MMU stays disabled after a restart."
- "`X` resets are only done when the MMU is enabled."
- Without parameters, `M709` only prints the MMU state (`MMU is ON` or `MMU is OFF`).

parameters:
- tag: S
  optional: true
  description: Enable (1) or disable (0) the MMU
  values:
  - tag: enable
    type: bool
- tag: X
  optional: true
  description: "Reset the MMU: 0 for a software reset, 1 to pulse the reset pin, 42 to erase the MMU EEPROM"
  values:
  - tag: reset
    type: int

examples:
- pre: Enable the MMU
  code: M709 S1
- pre: Software-reset the MMU
  code: M709 X0
- pre: Print the current MMU state
  code: M709
---

`M709` turns the MMU on or off and resets it. Use `X42` only when you intend to erase the MMU's own EEPROM.
