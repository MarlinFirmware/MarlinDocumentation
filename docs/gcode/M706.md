---
tag: m0706
title: "M706: Cut Filament"
short_title: Cut Filament
brief: Cut filament in an MMU slot with the MMU cutter
author: perkins
parent: G-code Commands
group: control
since: 2.1.3
requires: PRUSA_MMU3
codes: [ M706 ]
related: [ M704, M705 ]

notes:
- Does nothing unless the MMU is enabled and `P` names a valid slot.
- Only has an effect on an MMU with a cutter, when the MMU's cutter mode is on (`MMU3_HAS_CUTTER` in the MMU settings).

parameters:
- tag: P
  optional: false
  description: Index of the MMU slot, zero-based (0 to 4, that is `T0` to `T4`)
  values:
  - tag: slot
    type: int

examples:
- pre: Cut the filament in slot 1
  code: M706 P1
---

`M706` cuts the filament in the given MMU slot. On an MMU without a cutter, or with the cutter off, the command does nothing.
