parent: G-code Commands

codes: [ M203 ]

notes:
- View the current setting with [`M503`](/docs/gcode/M503.html).
- If `EEPROM_SETTINGS` is enabled, these are saved with [`M500`](/docs/gcode/M500.html), loaded with [`M501`](/docs/gcode/M501.html), and reset with [`M502`](/docs/gcode/M502.html).
- On Core, Delta, SCARA, and Polar machines these limits apply to each motor (belt, tower carriage, or joint), not to the nozzle. On a Delta, X, Y, and Z are towers A, B, and C and should be set to the same value. See [Motion Limits on Non-Cartesian Machines](/docs/settings/kinematics.html#motion-limits-on-non-cartesian-machines).
