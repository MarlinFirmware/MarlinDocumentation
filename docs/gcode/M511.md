---
tag: m0511
title: "M511: Unlock Machine"
short_title: Unlock Machine
brief: Unlock the machine if it has a passcode
author: shitcreek, thinkyhead

parent: G-code Commands
group: security
since: 2.0.6.1
requires: PASSWORD_UNLOCK_GCODE

codes: [ M511 ]
related: [ M510, M512 ]

parameters:

- tag: P
  optional: false
  description: The passcode to try.
  values:
  - tag: passcode
    type: int

example:
- pre: Unlock a machine with passcode '12345'
  code: M511 P12345

---

Check the given passcode and unlock the machine if it is correct; otherwise print `Incorrect Password`. Does nothing when the printer is not locked, and prints nothing on success.

See [Password](/docs/features/password.html) for the full feature.
