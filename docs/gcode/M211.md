---
tag: m0211
title: "M211: Software Endstops"
short_title: Software Endstops
brief: Set/report the software endstops state
author: thinkyhead

parent: G-code Commands
group: motion
requires: (MIN|MAX)_SOFTWARE_ENDSTOPS

codes: [ M211 ]

notes:
- Requires either `MIN_SOFTWARE_ENDSTOPS` or `MAX_SOFTWARE_ENDSTOPS` for the enable option.
- On a SCARA with software endstops enabled, a target the arms can't reach is moved to the nearest point that they can reach inside the limits. With software endstops disabled such a target is refused. See [SCARA](/docs/settings/scara.html#coordinates-and-limits).

parameters:
- tag: S
  optional: true
  type: bool
  description: Software endstops state
  values:
  - tag: 0
    type: bool
    description: Disable software endstops
  - tag: 1
    type: bool
    description: Enable software endstops

---

Optionally enable/disable software endstops, then report the current state.

With software endstops enabled, moves will be clipped to the physical boundaries from `[XYZ]_MIN_POS` to `[XYZ]_MAX_POS`.
