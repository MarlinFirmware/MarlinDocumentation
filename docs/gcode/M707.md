---
tag: m0707
title: "M707: Read MMU Register"
short_title: Read MMU Register
brief: Read a register from the MMU and print its value
author: perkins
parent: G-code Commands
group: debug
since: 2.1.3
requires: PRUSA_MMU3
codes: [ M707 ]
related: [ M708, M709 ]

notes:
- Does nothing if `A` is missing or the MMU is not enabled.
- The value is printed on the serial port.

parameters:
- tag: A
  optional: false
  description: Address of the MMU register, in hexadecimal
  values:
  - tag: address
    type: hex

examples:
- pre: Read register 0x1b
  code: M707 A0x1b
---

`M707` reads one register of the MMU. It is a diagnostic tool for MMU firmware work; normal printing does not need it.
