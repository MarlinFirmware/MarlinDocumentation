- tag: P
  requires: SET_PROGRESS_PERCENT
  optional: true
  description: Set current print progress percentage (0-100). Accepts decimals with `PRINT_PROGRESS_SHOW_DECIMALS` or `SHOW_REMAINING_TIME`. A non-zero value overrides the progress computed from the media file position; `P0` hands it back.

  - tag: percent

  since: 2.0.0
  requires: SET_REMAINING_TIME
  optional: true
  description: Set remaining time.
  values:
  - tag: minutes
    type: int

- pre: Set print progress to 25% and remaining time to 43.0 minutes
  code: M73 P25 R43
- pre: Report current values
  post: Requires `M73_REPORT`
  code: M73

---

Set next interaction countdown, current print progress percentage, and/or remaining time for display on the LCD. With `M73_REPORT` every `M73` reports the current values (only during media prints when `M73_REPORT_SD_ONLY` is also enabled). `R` and `C` are shown as given; Marlin does not count them down.

See [Print Progress and Statistics](/docs/features/print_progress_stats.html).
