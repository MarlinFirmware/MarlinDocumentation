---
tag: m0587
title: "M587: MKS WiFi Network"
short_title: MKS WiFi Network
brief: Set or report the network of an MKS WiFi module, or update its firmware
author: thinkyhead

parent: G-code Commands
group: ethernet
since: 2.1.3
requires: MKS_WIFI_MODULE

codes: [ M587 ]

notes: |
  - Settings are applied to the module as soon as the command runs. Use `M500` to save them to EEPROM.
  - The password is not reported. Reporting with `M587` or `M503` shows the SSID and mode only.
  - Without `GCODE_QUOTED_STRINGS`, the parser gives the first non-numeric parameter the whole rest of the line as a string. Only one string fits per command, so put numeric parameters (`A`) before `S` and `P`. For example, `M587 A0 SMyNetwork`.
  - `M587` with no parameters reports the current settings.
  - `U` replaces the module's firmware with `MksWifi.bin` from the media, and takes up to a minute. It refuses to run while printing.

parameters:

- tag: S
  optional: true
  description: The network to join, or to host in access point mode
  values:
  - tag: ssid
    type: string

- tag: P
  optional: true
  description: The network password. Use `P""` for an open network.
  values:
  - tag: password
    type: string

- tag: A
  optional: true
  description: Set `1` to host an access point, or `0` to join a network. Leave it out to keep the current mode.
  values:
  - tag: bool
    type: bool

- tag: U
  optional: true
  type: flag
  description: Update the module's firmware from `MksWifi.bin` on the media

examples:

- pre: Join a network called MyNetwork
  code: M587 A0 SMyNetwork
- pre: Set the password for the network
  code: M587 PMyPassword
- pre: Report the current network settings
  code: M587
- pre: Update the WiFi module from MksWifi.bin on the media
  code: M587 U

---

`M587` sets the WiFi network used by the MKS WiFi module found on some MKS boards. You can join an existing network, or have the module host its own access point so that you can connect to it directly. Boards with the `TFT_LVGL_UI` screens can change the same settings from the display.
