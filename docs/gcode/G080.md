---
tag: g080
title: "G80: Cancel Current Motion Mode"
short_title: Cancel Current Motion Mode
brief: Cancel the current motion mode
author: shitcreek

parent: G-code Commands
group: motion
since: 2.0.0
requires: GCODE_MOTION_MODES

codes: [ G80 ]

example:
- pre: 'Set motion mode G0, move with coordinates only, then cancel it'
  code:
  - G0 ; sets motion mode to G0
  - X10 Y10 ; moves to X10 Y10 in motion mode G0
  - G80 ; cancels the current motion mode
  - X20 Y20 ; no motion mode, so this is an unknown command

---

With `GCODE_MOTION_MODES` enabled, each `G0`, `G1`, `G2`, `G3`, `G5` (and `G38.x`) command also sets the current *motion mode*. Following lines can then give just coordinates and feedrate (for example `X10 Y20 F3000`) and Marlin treats them as that same command.

`G80` cancels the motion mode, so the next move must name its G-code again. Marlin does not implement CNC canned cycles, and `G80` has no other effect.
