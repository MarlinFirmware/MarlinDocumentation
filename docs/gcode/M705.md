---
tag: m0705
title: "M705: Eject Filament"
short_title: Eject Filament
brief: Eject filament from an MMU slot
author: perkins
parent: G-code Commands
group: control
since: 2.1.3
requires: PRUSA_MMU3
codes: [ M705 ]
related: [ M704, M706 ]

notes:
- Does nothing unless the MMU is enabled ([`M709`](/docs/gcode/M709.html)) and `P` names a valid slot.

parameters:
- tag: P
  optional: false
  description: Index of the MMU slot, zero-based (0 to 4, that is `T0` to `T4`)
  values:
  - tag: slot
    type: int

examples:
- pre: Eject the filament from slot 0
  code: M705 P0
---

`M705` ejects the filament from the given MMU slot. Use [`M704`](/docs/gcode/M704.html) to load it again.
