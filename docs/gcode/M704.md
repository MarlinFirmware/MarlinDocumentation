---
tag: m0704
title: "M704: Preload to MMU"
short_title: Preload to MMU
brief: Load filament from an MMU slot to the MMU feeder
author: perkins
parent: G-code Commands
group: control
since: 2.1.3
requires: PRUSA_MMU3
codes: [ M704 ]
related: [ M705, M706 ]

notes:
- Does nothing unless the MMU is enabled ([`M709`](/docs/gcode/M709.html)) and `P` names a slot from 0 to `EXTRUDERS - 1`. Without a valid `P` it does nothing.
- Select the MMU with [`MMU_MODEL`](/docs/settings/multi_material.html#MMU_MODEL) set to `PRUSA_MMU3`.

parameters:
- tag: P
  optional: false
  description: Index of the MMU slot, zero-based (0 to 4, that is `T0` to `T4`)
  values:
  - tag: slot
    type: int

examples:
- pre: Preload the filament in slot 2
  code: M704 P2
---

`M704` asks the MMU to load the filament in the given slot to its feeder, so it is ready for a tool change. It is the feeder-side counterpart of [`M705`](/docs/gcode/M705.html), which ejects the filament.
