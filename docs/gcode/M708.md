---
tag: m0708
title: "M708: Write MMU Register"
short_title: Write MMU Register
brief: Write a value to an MMU register
author: perkins
parent: G-code Commands
group: debug
since: 2.1.3
requires: PRUSA_MMU3
codes: [ M708 ]
related: [ M707, M709 ]

notes:
- Does nothing if `A` is missing, if the MMU is not enabled, or if the address is `0x00`.
- Writing a register changes MMU behavior directly. Change a register only when you know what it does.

parameters:
- tag: A
  optional: false
  description: Address of the MMU register, in hexadecimal
  values:
  - tag: address
    type: hex
- tag: X
  optional: true
  description: Value to write (16-bit). Defaults to 0.
  values:
  - tag: data
    type: int

examples:
- pre: Write the value 5 to register 0x1b
  code: M708 A0x1b X5
---

`M708` writes one register of the MMU. Pair it with [`M707`](/docs/gcode/M707.html) to read the value back.
