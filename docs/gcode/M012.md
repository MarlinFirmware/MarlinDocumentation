---
tag: m0012
title: "M12: Closed Loop Sync"
short_title: Closed Loop Sync
brief: Wait for queued moves, then optionally set the closed loop controller enable pin
author: thinkyhead

parent: G-code Commands
group: control
since: 2.0.0
requires: EXTERNAL_CLOSED_LOOP_CONTROLLER

codes: [ M12 ]

notes: |
  - The `CLOSED_LOOP_ENABLE_PIN` and `CLOSED_LOOP_MOVE_COMPLETE_PIN` must both be defined. The firmware refuses to build without them.
  - `M12` always waits for all queued moves to finish before it does anything else.

parameters:

- tag: S
  optional: true
  description: The value to write to the closed loop enable pin. Use `0` or `1`.
  values:
  - tag: val
    type: int

examples:

- pre: Wait for queued moves to finish, and leave the enable pin as it is
  code: M12
- pre: Wait for queued moves, then force the enable pin to the given value
  code: M12 S1

---

Synchronize with an external closed loop controller. `M12` waits for the planner to empty before it runs, so it takes effect after all earlier moves have finished. If `S` is given, the value is written to the closed loop enable pin.
