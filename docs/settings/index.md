# Settings

Every option in `Configuration.h` and `Configuration_adv.h`, grouped by the `@section` it belongs to in the configuration files. Each option shows the file it comes from, its type, and the version it first appeared in. Related options for multiple axes, extruders, or heaters are shown together with a single description.

For an explanation of what a feature does and how its options work together, see its Features page.
