settings:
- name: NUM_SERVOS
  file: Configuration.h
  type: int
  default: 3
  disabled: true
  long: |-
    ![Servo](/assets/images/config/servo.png){: .float-right .framed }

    The total number of servos to enable for use. One common application for a servo is a Z bed probe consisting of an endstop switch mounted on a rotating arm. To use one of the servo connectors for this type of probe, set `Z_PROBE_SERVO_NR` in the probe options above.
  comment: |-
    Number of servos

    For some servo-related options `NUM_SERVOS` will be set automatically. Set this manually if there are extra servos needing manual control. Set to 0 to turn off servo support.
- name: SERVO_DELAY
  file: Configuration.h
  type: int[]
  default: '{ 300 }'
  units: ms
  long: Delay (in microseconds) before the next move will start, to give the servo time to reach its target angle. 300ms is a good value but you can try less delay. Specify a large enough delay so the servo has enough time to complete a full motion before deactivation.
  comment: (ms) Delay before the next move will start, to give the servo time to reach its target angle. 300ms is a good value but you can try less delay. If the servo can't reach the requested position, increase it.
- name: DEACTIVATE_SERVOS_AFTER_MOVE
  file: Configuration.h
  type: switch
  disabled: true
  long: With this option servos are powered only during movement, then turned off to prevent jitter. We recommend enabling this option to keep electrical noise from active servos from interfering with other components. The high amperage generated by extruder motor wiring during movement can also induce movement in active servos. Leave this option enabled to avoid all such servo-related troubles.
  comment: Only power servos during movement, otherwise leave off to prevent jitter
- name: EDITABLE_SERVO_ANGLES
  file: Configuration.h
  type: switch
  disabled: true
  comment: Edit servo angles with M281 and save to EEPROM with M500
- name: SERVO_DETACH_GCODE
  file: Configuration.h
  type: switch
  disabled: true
  comment: Disable servo with M282 to reduce power consumption, noise, and heat when not in use

Options in the `servos` section of the Marlin configuration files.
